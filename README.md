# Jake C. Ardenio Biochemistry E-Portfolio

A static portfolio prepared for GitHub and Cloudflare Pages. No build step is required.

## Deploy to Cloudflare Pages

1. Upload the full project folder to a GitHub repository.
2. In Cloudflare Pages, choose **Connect to Git** and select the repository.
3. Set **Framework preset** to `None`.
4. Leave **Build command** empty.
5. Set **Build output directory** to `/`.
6. Deploy.

The embedded communication video is already compressed for web delivery. Keep the `assets` folder beside `index.html`.
